YFLOW DOMAIN MODEL VOLUME 2 - SYSTEM BEHAVIOR DOMAIN
=====================================

PURPOSE

Defines how entities behave.

1.  ENTITY LIFECYCLE

Workspace Draft Active Suspended Archived

Project Draft Planning Active Completed Archived

Workflow Draft Active Completed Archived

Task Draft Todo In Progress Review Approved Done Archived

------------------------------------------------------------------------

2.  BUSINESS RULES

Workspace - Must have one owner.

Project - Cannot archive with active tasks.

Workflow - Cannot complete if unfinished stages exist.

Stage - Cannot close with open tasks.

Task - Cannot complete when checklist incomplete.

Checklist - Parent task progress updates automatically.

------------------------------------------------------------------------

3.  PERMISSION MATRIX

Super Admin Everything

Workspace Admin Workspace management

Operations Manager All projects Assignments Reports

Project Manager Own projects

Contributor Assigned tasks

Client Read and approve
