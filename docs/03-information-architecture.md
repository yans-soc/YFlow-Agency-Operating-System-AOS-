# Information Architecture — YFlow

## Overview
Hierarchical structure of YFlow data and navigation.

## Hierarchy
```
Workspace (Root)
├── Departments
│   └── Teams
│       ── People
── Projects
│   ├── Tasks
│   │   ├── Assignees
│   │   └── Checklists
│   ── Workflows
│       └── Stages
├── Calendar Events
── Notes
── Files
── Notifications
```

## Navigation Structure
- Workspace Settings
- Projects List → Project Detail
- People Directory → Person Profile
- Calendar
- Notifications Center
