# 01 — Vision

# YFlow — AI Agency Operating System (AOS)

## Vision Statement

YFlow adalah platform **AI Agency Operating System**, bukan sekadar Project Management.

### Core Philosophy

- **Manual-first, AI-assisted** — Pengguna selalu memegang kendali
- **AI sebagai co-pilot** — Advisor, planner, dan optimizer
- **Workflow Intelligence** — Sistem menyimpan cara terbaik menyelesaikan pekerjaan

---

## Primary User Flow

```
Client Brief 
    → AI Analysis (opsional) 
    → Project Blueprint 
    → Workflow 
    → Schedule 
    → Execution 
    → Learning 
    → Optimization
```

Semua proses dapat dibuat dengan:
1. Manual
2. Template
3. Marketplace
4. AI Generate

---

## Core Engines

| Engine | Description |
|--------|-------------|

## Key Differentiator

> YFlow tidak hanya menyimpan task. YFlow menyimpan **cara terbaik menyelesaikan pekerjaan** (Workflow Intelligence). 

Semakin banyak project berjalan, semakin cerdas rekomendasi:
- Workflow templates
- Time estimations
- Scheduling suggestions
- Optimization strategies
