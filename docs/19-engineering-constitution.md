# Engineering & AI Constitution — YFlow

## Core Principles
1. **Documentation First** - No code without docs
2. **Tests Required** - 80%+ coverage minimum
3. **One Module Per Session** - Complete before moving on
4. **Follow Business Rules** - Never violate documented rules
5. **API Versioning** - Breaking changes require new version

## Code Standards
- PSR-12 for PHP
- Strict TypeScript
- ESLint + Prettier enforced
- Conventional Commits

## Review Process
- Self-review first
- Peer review required
- CI must pass
- Documentation updated

## AI Agent Rules
- Read docs before coding
- Ask if uncertain
- Stop after module complete
- Update docs after changes
